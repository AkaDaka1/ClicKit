# CHANGELOG — ClicKit

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-29

Первый публичный релиз: продукт готов к использованию вне исходников.
Вехи M0–M5 завершены и влиты в `master` (M5 — PR #1).

### Добавлено

- **Темы оформления:** «Как в системе» (по умолчанию), «Тёмная», «Светлая».
  GUI и холст Blockly переключаются вместе; в системном режиме приложение
  следует за темой Windows, в том числе при её смене на лету.
- **Диалог настроек** (`Настройки → Параметры…`, `Ctrl+,`): выбор темы и запись
  трёх глобальных хоткеев (старт, стоп, захват точки) с проверкой конфликтов,
  сбросом к F5/F6/F8 и применением без перезапуска.
- **Журналирование:** `%APPDATA%\ClicKit\logs\app.log` (UTF-8, ротация
  1 МБ × 3), UTF-8-консоль, перехват необработанных исключений с понятным
  диалогом и путём к журналу; меню «Помощь → Открыть папку журналов».
- **Сборка релиза:** onedir-архив `ClicKit-win64.zip` (рекомендуется, старт
  за секунды) — основной артефакт GitHub Release; альтернативный один файл
  `ClicKit.exe` собирается локально (`--onefile`); иконка `app.ico`, свойства
  версии 1.0.0, `NOTICE.txt` со сторонними лицензиями и `SHA256SUMS.txt`.
- **CI/CD:** GitHub Actions на `windows-latest` — линтер и автотесты на Python
  3.11–3.13, сборка архива на `master`, релиз по тегу `v<версия>` с проверкой
  версии, контрольных сумм и смоук-запуском собранного `.exe`, автоматической
  публикацией GitHub Release и заметками из этого файла.
- **Документация:** `CHANGELOG.md`, обновлённые README (EN/RU), `AI_CONTEXT.md`
  (ADR №25–32, схема CI/CD), `PROGRESS.md`, `ROADMAP.md`, `AGENTS.md`.

### Изменено

- Хоткеи в настройках нормализуются при загрузке; испорченный `settings.json`
  больше не роняет запуск — невалидное сочетание заменяется значением
  по умолчанию.
- Версия приложения вынесена в `app/version.py`; формат настроек — версия 2
  (старые файлы читаются совместимо).
- Подсказки в статус-баре, на кнопках, в трее и тулбаре редактора показывают
  актуальные (в том числе переназначенные) сочетания.

### Исправлено

- Фон диалогов в тёмной теме (диалог настроек и окна сообщений больше не
  остаются светлыми).
- Светлая тема: контрастные панели, поля ввода и подсветка выполняемого блока.

### Ограничения 1.0.0

- Интерфейс только на русском; локализация RU+EN — после 1.0.0.
- Условия (`if`/`loop while`) и запись действий (`recorder.py`) не входят
  в релиз: узел `if` зарезервирован в IR.
- Onefile-сборка распаковывает ~220 МБ QtWebEngine при каждом запуске,
  поэтому стартует заметно дольше onedir (на тестовой машине ~1 минута).
- Сборки не подписаны: SmartScreen может попросить подтверждение.
- GitHub Release содержит только `ClicKit-win64.zip`; `ClicKit.exe` (onefile)
  собирается отдельной командой `--onefile` и рекомендуется только при
  необходимости единого файла.
